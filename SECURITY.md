# Security Policy

## Supported Versions
Security updates are actively maintained on the latest release of DocuTrust:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
We take cryptographic and ledger integrity vulnerabilities very seriously. 
If you discover a security vulnerability in DocuTrust, please report it via private GitHub Security Advisory or email the core maintainers directly at `security@docutrust.org`.

Please include:
1. Proof of concept demonstrating the vulnerability or collision.
2. Steps to reproduce.
3. Affected components (e.g. `@docutrust/core`, CLI, API).
