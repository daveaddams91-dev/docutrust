# Docutrust

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![CI](https://github.com/rajveersinh-is-dev/docutrust/actions/workflows/ci.yml/badge.svg)](https://github.com/rajveersinh-is-dev/docutrust/actions)


Sovereign trust fabric for verifiable credentials, autonomous agent identity federation, confidential mixnets, RAG provenance, and zero-knowledge state machines.

## Features

- Clean, modern Python 3.10+ implementation.
- Typed signatures and robust error handling.
- Comprehensive unit test coverage.

## Installation & Usage

```bash
git clone https://github.com/rajveersinh-is-dev/docutrust.git
cd docutrust
python "sdks/python/docutrust/__init__.py" --help
```

## Testing

```bash
pytest tests/
```
